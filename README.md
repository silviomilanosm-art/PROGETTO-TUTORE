# PROGETTO TUTORE

App Android per la progettazione parametrica di tutori artigianali per mano, polso e avambraccio.

## Prima versione
- Inserimento misure anatomiche
- Calcolo indicativo dei componenti tessili e delle fasce
- Riepilogo dei pezzi da tagliare
- Note cliniche e costruttive

> Strumento di supporto alla progettazione e documentazione. Le misure finali, le forze applicate e la sicurezza del dispositivo devono essere verificate dal professionista sul paziente.
